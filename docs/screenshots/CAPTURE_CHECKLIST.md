# Checklist de capturas

Guarda las imagenes en esta carpeta con estos nombres exactos:

1. `home.png`
- Ruta: `/`
- Estado: usuario logeado
- Mostrar: hero + listado de testimonios

2. `login-register.png`
- Ruta: `/login`
- Mostrar: tabs de iniciar sesion y registrarse

3. `admin.png`
- Ruta: `/admin`
- Estado: sesion ADMIN o EDITOR
- Mostrar: tabla de testimonios y acciones

4. `new-testimonial.png`
- Ruta: `/testimonials/new`
- Estado: sesion USER
- Mostrar: formulario con nombre bloqueado por usuario

Recomendacion:
- Resolucion: 1280x720 o 1440x900
- Formato: PNG
- Evita datos sensibles en las capturas
